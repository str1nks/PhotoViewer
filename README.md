# PhotoViewer

**Быстрый просмотрщик фото и видео для Windows в стиле Windows 11 (Fluent)**

Плавный зум к курсору, перетаскивание с инерцией, повороты, встроенное видео со звуком и полноэкранный режим. Один файл, без установки.

## Возможности

**Фото**
- Форматы: `JPG`, `JPEG`, `PNG`, `BMP`, `GIF`, `WebP`, `TIF`, `TIFF`, `ICO`.
- **Плавный зум** колесом мыши к курсору, от 2% до 3200%.
- **Перетаскивание с инерцией** приближенного фото.
- **Поворот** на 90° вправо и влево.
- Двойной клик вписывает фото в окно или приближает его.
- **Автоповорот по EXIF**: фото с телефона открываются правильной стороной.
- **Информация о файле** под фото: имя, размер в пикселях, вес, формат, дата съёмки (из EXIF, а если её нет, то дата изменения файла).
- Плавные анимации: кроссфейд при переключении, анимация зума и вписывания.

**Видео**
- Форматы: `MP4`, `AVI`, `MKV`, `MOV`, `WMV`, `WebM`, `M4V`.
- Воспроизведение начинается сразу при открытии, **со звуком**.
- Пауза, перемотка ползунком и на 5 секунд, громкость, выключение звука.
- Звук извлекается встроенным ffmpeg (пакет `imageio-ffmpeg`), отдельно ставить ffmpeg не нужно. Если звуковой карты нет, видео играет без звука.

**Интерфейс**
- Оформление Windows 11: нижняя панель с иконками Segoe Fluent, цветной заголовок окна под цвет фона.
- Светлая и тёмная тема подстраиваются под систему.
- **Полноэкранный режим** (`F11`): панель сама прячется и появляется при движении мыши.
- Листание всех фото и видео в папке, где лежит открытый файл (естественная сортировка: `img2` идёт перед `img10`).
- Свой значок на панели задач.

**Интеграция с Windows**
- Собранный `.exe` при первом запуске **предложит сделать PhotoViewer программой для фото и видео**: он копируется в `%LOCALAPPDATA%\Programs\PhotoViewer`, регистрируется в «Приложениях по умолчанию» и в меню «Открыть с помощью». Права администратора не нужны, всё пишется в раздел текущего пользователя.
- Полное удаление: через «Установленные приложения» или командой `PhotoViewer.exe --unregister`.

## Управление

| Действие | Клавиши / жесты |
| --- | --- |
| Предыдущее / следующее | `←` / `→` |
| Первый / последний файл | `Home` / `End` |
| Приближение / отдаление | колесо мыши, `+` / `-` |
| Вписать в окно | `0`, двойной клик |
| Перемещение | перетаскивание мышью |
| Повернуть вправо / влево | `R` / `Shift+R` или `L` |
| Открыть файл | `Ctrl+O` |
| Полный экран / выход | `F11` / `Esc` |

Для видео:

| Действие | Клавиши |
| --- | --- |
| Пауза / продолжить | `Пробел` |
| Перемотка на 5 секунд | `Shift+←` / `Shift+→` |
| Звук вкл / выкл | `M` |
| Громкость | `↑` / `↓` |
| Перемотка в любое место | ползунок |

Горячие клавиши работают и в русской раскладке.

## Установка и запуск

### Готовый .exe

Скачайте `PhotoViewer.exe` из раздела [Releases](../../releases) и запустите. Python устанавливать не нужно.

### Из исходников

```bash
pip install -r requirements.txt
python photo_viewer.py [путь_к_фото]
```

Путь к фото можно не указывать: файл открывается через `Ctrl+O`.

## Сборка .exe

В репозитории есть готовый файл сборки `PhotoViewer.spec`:

```bash
pip install -r requirements.txt pyinstaller
pyinstaller PhotoViewer.spec
```

Результат: `dist\PhotoViewer.exe`. Это один файл без консольного окна, со значком `icon.ico`. Ресурсы `customtkinter`, `imageio-ffmpeg` и `sounddevice` собираются в него автоматически.

Если установлен [UPX](https://upx.github.io/), PyInstaller дополнительно сожмёт файл. Если нет, сборка пройдёт без сжатия.

## Требования

- Windows 11 (значки на панели используют шрифт Segoe Fluent Icons; на Windows 10 он может отсутствовать, и тогда вместо иконок будут пустые квадраты).
- Python 3 для запуска из исходников.
